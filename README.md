### 3. Реализация ядра системы

3.1. Аутентификация и авторизация:

* Django Auth + JWT/сессии.
* Роли и разрешения (RBAC).
* Двухфакторная аутентификация (для Root и Админа).

3.2. Управление пользователями:

* CRUD для пользователей и ролей.
* Привязка к департаментам и группам.

3.3. Модель резюме (Entity + EntityData):

* Поддержка динамических полей (Template и TemplateField).
* Валидация формата email, телефонов.

3.4. Работа с файлами:

* Django Storage + локальное хранилище (опционально AWS S3).
* Контроль размера и типа файла.
* Хэш-суммы (checksum).

3.5. Логирование действий:

* Логи авторизаций, изменений данных, загрузок/удалений.
* Каналы: бизнес-логи и тех.логи.
