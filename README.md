# 📅 Дорожная карта разработки (HRResumeBank)

## 🔹 Спринт 1 (2 недели) – Базовая инфраструктура и архитектура

* [x] Настройка Git-репозитория + CI/CD (GitHub Actions).
* [x] Создание Docker-окружения (Postgres + Django + Nginx).
* Инициализация Django-проекта (структура приложения, настройки).
* [x] Настройка линтеров (flake8, black, isort, mypy).
* Подготовка базовой модели данных (User, Role, Permission, Department).

👉 Результат: проект поднимается в Docker, есть базовые таблицы и миграции.

## 🔹 Спринт 2 (2 недели) – Аутентификация и роли

* Django Auth + регистрация пользователей.
* JWT / сессии Django.
* Подтверждение email при регистрации.
* Роли и разрешения (RBAC: Root, Admin, Editor, Reader).
* Ограничение доступа по ролям (Django Permissions + кастомная логика).
* Тесты: авторизация, роли, защита API.

👉 Результат: система различает пользователей по ролям, работает логин/регистрация.

---

## 🔹 Спринт 3 (2 недели) – Управление пользователями и организациями

* CRUD для пользователей (Админ может добавлять/блокировать).
* Привязка пользователей к департаментам и группам.
* UI: форма регистрации, форма редактирования пользователя.
* API: управление пользователями.
* Логирование действий (создание/блокировка).

👉 Результат: администратор может управлять пользователями и их ролями.

---

## 🔹 Спринт 4 (2 недели) – Шаблоны резюме и динамические поля

* Реализация `Template` и `TemplateField`.
* Возможность добавлять новые поля (string, number, date, file, boolean).
* Сущность `Entity` (резюме/карточка).
* `EntityData` (значения динамических полей).
* Валидация форм (email, телефон, дата рождения).
* UI: форма добавления резюме (drag\&drop файлов).

👉 Результат: редактор и админ могут добавлять резюме с динамическими полями.

## 🔹 Спринт 5 (2 недели) – Поиск и работа с файлами

* Полнотекстовый поиск (Postgres tsvector, pg\_trgm).
* Фильтры (ФИО, должность, дата, департамент, динамические поля).
* Lazy loading, пагинация, сохранение фильтров.
* Модуль файлового хранилища (`FileStorage`): загрузка, скачивание, checksum.
* Ограничения: тип/размер файла.

👉 Результат: поиск по резюме работает, файлы можно загружать и скачивать.

---

## 🔹 Спринт 6 (2 недели) – Логирование и безопасность

* Бизнес-логи (создание резюме, изменения).
* Технические логи (авторизация, ошибки, попытки взлома).
* Автоблокировка после 5 неудачных попыток входа.
* Шифрование конфиденциальных данных (AES-256).
* HTTPS (TLS 1.2+).
* Тесты OWASP (SQLi, XSS, CSRF).

👉 Результат: система безопасна, все действия пользователей фиксируются.
