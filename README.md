## Руководство администратора системы HR Resume Bank

### 1. Введение

Это руководство предназначено для администраторов системы HR Resume Bank. Здесь описаны шаги по установке, настройке, обновлению и обслуживанию системы, а также приведены рекомендации по устранению наиболее распространенных технических проблем.

### 2. Установка системы

#### 2.1. Минимальные системные требования:
- Операционная система: Debian 12
- Процессор: Intel Core i5 или эквивалент AMD
- RAM: минимум 4 ГБ оперативной памяти
- Свободное пространство на диске: минимум 20 ГБ
- Интернет-подключение

#### 2.2. Шаги установки:
1. Установите необходимые зависимости (Docker, Docker Compose, git):

```bash
sudo apt update && sudo apt install docker.io docker-compose git
```

2. Скачайте репозиторий проекта с GitHub:

```bash
git clone https://github.com/GenyaElamkov/HRResumeBank.git
```

3. Откройте папку проекта и создайте .env файл:

```bash
cp .env.example .env
```

4. Измените значения переменных окружения в файле .env согласно вашим требованиям.
5. Замените server_name в файле nginx/nginx.conf на свой
6. Соберите Docker-образы и запустите контейнеры:

```bash
make app-prod
```

6. Посмотреть логи работы контейнеров:

```bash
make app-logs
```

---

### 3. Настройка системы

#### 3.1. Настройка базы данных:

1. Убедитесь, что база данных PostgreSQL запущена внутри контейнера Docker.
2. Используйте следующую команду для миграции схемы базы данных:

```bash
make migrate
```

#### 3.2. Настройка пользователя root:

Создать суперпользователя можно командой:

```bash
make superuser
```

Следуйте инструкциям по вводу имени пользователя, электронной почты и пароля.

---

### 4. Резервное копирование и восстановление

#### 4.1. Ежедневное резервное копирование:

Система настроена на ежедневное автоматическое резервное копирование базы данных PostgreSQL. Вы можете настроить расписание вручную, добавив cron-задачу:

```bash
0 2 * * * docker exec -it hr_resume_bank_db pg_dump -U postgres dbname > backup.sql
```

Где `dbname` — имя вашей базы данных.

#### 4.2. Восстановление из резервной копии:

При необходимости восстановить базу данных выполните следующее:

1. Остановите контейнер базы данных:

```bash
make app-prod-down
```

2. Удалите старый контейнер базы данных:

```bash
docker rm hr_resume_bank_db
```

3. Создайте новый контейнер и восстановите базу данных из резервной копии:

```bash
docker run -v $(pwd)/backup.sql:/backup.sql postgres bash -c "psql -U postgres dbname < /backup.sql"
```

---

### 5. Обновление системы

Чтобы обновить систему до последней версии, выполните следующие шаги:

1. Сделайте pull последнего commit из удалённого репозитория:

```bash
git pull origin main
```

2. Повторите процесс сборки Docker-образов и запуска контейнеров:

```bash
make app-prod && make app-logs
```

3. Примените любые доступные миграции базы данных:

```bash
make migrate
make migrations
```

---

### 6. Решение проблем

#### 6.1. Проблемы с базой данных:

Если возникают проблемы с подключением к базе данных, убедитесь, что PostgreSQL запущен и слушает правильный порт (обычно 5432). Проверьте правильность настроек подключения в файле settings.py.

#### 6.2. Медленная работа системы:

Проверьте производительность базы данных, проведите индексацию больших таблиц и очистите кэш системы. Увеличьте количество ресурсов (RAM, CPU) выделяемых Docker-контейнеру.
